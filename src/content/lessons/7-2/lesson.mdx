## About this practice exam

This exam has **15 questions** drawn from the other three scenarios: **code generation with Claude Code**, **Claude Code for CI/CD** and **structured data extraction**. Together they concentrate on **Domain 3** (Claude Code Configuration & Workflows) and **Domain 4** (Prompt Engineering & Structured Output), which make up the remaining 40% of the exam's weight.

As in Exam A, every question is new and written to the exam's pattern, scoring is all-or-nothing on multi-select, and you pass with **12 of 15**. Give yourself **30 minutes**, answer everything, and note your confidence for each answer before you submit.

## What's different about Domains 3 and 4

Domains 1, 2 and 5 are mostly about **architecture judgment**. Domains 3 and 4 add more **precise facts**: where a file lives, which flag does what, which schema feature solves which problem. Two habits help:

- **Check the location or flag exactly.** `.claude/commands/` and `~/.claude/commands/` differ only in who gets the command, and that difference is usually the whole question. Options that name flags, files or settings that don't exist are common distractors.
- **Separate structure from meaning.** Tool use and JSON schemas guarantee output that parses and matches the schema. They don't guarantee the values are right. When a question says the output is valid but wrong, the answer is validation logic, examples or criteria, not a stricter schema.
